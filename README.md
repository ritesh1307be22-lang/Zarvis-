# 🤖 Zarvis – AI Virtual Assistant

Zarvis is an AI-powered virtual assistant built using Python and Streamlit. It provides voice-based interaction and performs real-time task automation with a modern, interactive interface.
## 🚀 Features
* 🎤 Voice command recognition (wake word: "Jarvis")
* 🧠 AI responses using local Phi-3 model (Ollama)
* 🌐 Open websites (Google, YouTube, LinkedIn, etc.)
* 📩 Send WhatsApp messages
* 🌦️ Get weather updates & latest news
* 📸 Take screenshots & capture photos
* 💻 Monitor system performance (CPU, battery)
* ⚡ Focus mode & workspace cleanup
* 📝 Session interaction history
---
## 🛠️ Tech Stack
* Python
* Streamlit
* SpeechRecognition
* gTTS (Text-to-Speech)
* OpenCV
* Ollama (Phi-3 Model)
* PyAutoGUI, Psutil, Pandas, NumPy
---
## 📦 Installation
```bash
git clone https://github.com/ritesh1307be22-lang/Zarvis-.git
cd Zarvis-
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```
## ▶️ Run the Project
```
streamlit run app.py
```
## ⚠️ Notes

* Make sure microphone access is enabled
* Ollama must be running locally for AI responses
* Do not upload `.venv` folder to GitHub
